# 🎨 DesignStocker

**DesignStocker** is a modern, full-stack directory of personally curated design resources. It's designed to help beginner and mid-level designers find the best tools and assets—like high-quality mockups, fonts, and stock images—all in one place.

## ✨ Features
- **Curated Library**: Hand-picked resources with professional ratings.
- **Search & Filter**: Find exactly what you need by category or keyword.
- **Community Reviews**: Real feedback from other designers.
- **Admin Dashboard**: Easy management of resources and categories.
- **Responsive Design**: Premium UI built with glassmorphism and smooth animations.

## 🚀 Tech Stack
- **Frontend**: [Next.js](https://nextjs.org/) (React), Vanilla CSS, Lucide Icons.
- **Backend**: [Node.js](https://nodejs.org/), Express.
- **Storage**: Local JSON database (Production-ready for volumes).

## 🛠️ Local Development

1. **Clone the repo**:
   ```bash
   git clone https://github.com/YourUsername/designstocker.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the app**:
   ```bash
   npm run dev
   ```
   *The frontend will run on `http://localhost:3000` and the API on `http://localhost:4000`.*
